# LimiTools — Transform Reset Buttons

![LimiTools_TRB_gif](https://github.com/user-attachments/assets/7db3de86-813e-42a5-a527-60fd66d8449e)<br>
_Tested on Unity 6, can't guarantee compatibility with previous versions._<br>
---
• one-click transform resets with multi-object support, fully undo-able<br>
• essentially does Right Click > Transform > Reset Property > Position/ Rotation/ Scale<br>
• hide by clicking the eye, restore from Tools > 🅻 Show Transform Reset Buttons<br>
• edit "enabledButtonColor" to style it to your liking

## To install– just drop the script in Assets/Editor/ or any Editor folder.
